# 国泰海通全天候指数（CI011001.WI）复刻

目标：用 tushare 数据复刻月报（`01_国泰海通_大类资产全周期产品2026年9月月报.pdf`）里的全天候指数。
校准目标有三组，都从月报中解析：

| 目标 | 文件 | 用途 |
|---|---|---|
| 指数月度收益 2009-01..2026-09 | `data/target/index_monthly.csv` | 收益拟合 |
| 1号产品分资产月度归因 2023-02..2026-09 | `data/target/attr_p1.csv` | 校准各资产的持有和止损时点 |
| p.3 调仓权重柱状图（按颜色数字化） | `data/target/chart_weights.csv` | 直接校准风险平价层（份额和杠杆） |

## 运行

```bash
export TUSHARE_TOKEN=...
uv sync
uv run python scripts/parse_report.py      # 月报 → data/target/*.csv
uv run python scripts/digitize_chart.py    # 权重图 → chart_weights.csv
uv run python scripts/fetch_data.py        # tushare → data/raw/*.parquet（有缓存）
uv run python scripts/run_final.py         # 最终回测 → results/，并打印当前信号和调仓日历
uv run python scripts/calibrate.py <stage> # 参数搜索：base|mom|stop|data|refine|final|fine
uv run python scripts/fit_rp_layer.py      # 用权重图拟合风险平价层
uv run python scripts/chart_match.py ...   # 检验调仓日程和图上月份标签的对应关系
```

## 资产与数据

| 资产 | 代码（tushare） | 说明 |
|---|---|---|
| 中国权益 | H00300.CSI（沪深300全收益） | 全收益略好于价格指数 |
| 美国权益 | SPX（index_global），美元计价 | 取上一自然日的美股收盘；美元版拟合略好于人民币版 |
| 中国债券 | 930849.CSI 中证10年国开债 | 明显好于 10 年国债、合成曲线和 T 期货，和月报里的「国开 7-10 年」一致 |
| 黄金/铜/原油 | AU.SHF / CU.SHF / SC.INE 主力 | 用 fut_mapping 加当日合约的 close/pre_close 拼成复权连续收益；SC 在 2018 年以前缺失（不用代理更好） |
| 现金 | SHIBOR 3M | 杠杆部分按现金利率融资（`cash_mode=residual`） |

## 最终规则（`allweather/config.py: FINAL`）

1. **调仓**：每 20 个上交所交易日一次，以 **2026-09-24** 为锚倒推和前推。下一次是 2026-10-30，之后是 11-27、12-25。
   - P=19/21/22 都比 20 差（P=21 时 2023 年后的月度相关从 0.94 降到 0.92）。锚点扫描时，9/18–9/29 拟合最好，归因相关在 9/23–9/24 达到峰值。
   - 权重图上的月份标签 = 持有期中点所在的月份，所以图上 2609 那根柱子对应 8/27 的调仓，9/24 的调仓不在本期图里。
2. **风险平价层**（用权重图直接识别）：用 250 日协方差做 **ERC，每个资产等风险预算**；然后用 **1000 日（约 4 年）协方差** 把组合缩放到目标波动 **5.5%**，gross 上限 2 倍。
   - 在债券持有的月份，模型和图的对比：总敞口相关 0.90，债券权重相关 0.90，债券占比平均误差 0.02。
   - 杠杆窗口很关键：用同一个 250 日窗口时，总敞口和图的相关只有约 0。
3. **调仓日过滤**：收盘价 ≤ MA45 的资产权重归零，转为现金。
   - 图上债券为 0 的月份总额恰好是 100%，说明「被过滤的权重显示为货币，债券不在时不加杠杆」。
4. **区间内止损**：持有期间某天收盘跌破 **MA60**，当天收盘出场，**直到下一个调仓日都不补回**。
   - 这正是你的猜测：动量类止损，止损后等到下个调仓日才回补。
   - 另一种「从调仓日起累计跌幅超过 1×该资产 20 日波动」的止损（`ALT_CUM`）全样本拟合略好，2023 年以后略差，两者很难区分。

## 拟合结果（月度，对比目标指数）

| 区间 | 相关 | TE | 年化（模型/目标） | 波动 | 最大回撤 |
|---|---|---|---|---|---|
| 2009-01..2026-09 | 0.83 | 2.35% | 7.1% / 8.8% | 3.4% / 4.3% | -2.8% / -3.6% |
| 2019-01.. | 0.90 | 1.75% | 9.3% / 9.4% | 4.0% / 4.0% | -2.0% / -2.1% |
| 2023-02..（产品实盘期） | 0.94 | 1.22% | 10.5% / 11.1% | 3.6% / 3.7% | -1.2% / -1.6% |

2023 年以后的年度收益相关 0.995。分资产归因的月度相关：A 股 0.78、美股 0.85、黄金 0.91、铜 0.94、原油 0.96、债券 0.94。

逐步加入各个组件时的月度相关（全样本）：纯风险平价 0.67 → 加调仓日动量过滤 0.79 → 再加区间内止损 0.83–0.84。

## 已知差异和待验证的点

- **2019 年以前拟合偏弱**（2009、2010、2014、2016 年模型明显跑输）。这一段是指数发布前的回测，早期可能用了不同的资产或代理（例如 2018 年以前没有 SC 原油），这里没能识别出来。
- **美股贡献偏低**：模型累计 2.0%，产品归因 6.5%。产品可能用 QDII ETF，或者权益内部的分配和模型不同；但给美股加预算并没有改善拟合。
- **债券贡献偏高**：模型 20.4%，产品 13.5%。产品可能用国债期货，收益里扣掉了资金成本，所以产品归因的水平不能直接对比。
- **软地板**（被过滤资产保留部分权重）、交易成本、权重漂移与否：对拟合几乎没有影响，数据里识别不出来。
- 2026 年模型的总敞口经常顶到 2.0，而图上最高约 1.93，真实上限可能略低于 2，或者目标波动约 5.3%。

## 宏观叠加（`allweather/macro.py`，配置 `config.MACRO`）

月报说指数构建里有「系统场景预判、动态预算微调」，所以在复刻规则之上加了一层宏观预算微调：
资产的风险预算乘以 `exp(k × 宏观打分)`，打分低于 `-veto` 时，调仓日直接不持有该资产。

```bash
uv run python scripts/fetch_macro.py     # PMI、CPI、PPI、M1/M2、社融、美债名义和实际收益率
uv run python scripts/macro_ic.py        # 15 个候选信号对未来 20 日收益的 IC，样本内外分开统计
uv run python scripts/macro_overlay.py   # 各叠加方案的回测，样本内 2009–2017，样本外 2018–2026
uv run python scripts/run_macro.py       # 采用方案和基准对比，并输出当前宏观读数
```

**防止未来函数**：月度数据都按发布时滞处理后再映射到交易日。PMI 次月 1 日起可用，CPI 和 PPI 次月 15 日起，M1/M2 和社融次月 20 日起；美债数据滞后 1 个自然日。z 值只用历史窗口计算。

**结论：多数宏观信号在样本外不稳定。**

- **IC 检验**：样本内 |IC| 超过 2 倍标准误的只有两个信号（M1−M2 剪刀差对债券 +0.21，美债名义利率变化对债券 -0.26）。到样本外，两个信号的方向都反转了。
- **信用扩张信号**（社融、M1、剪刀差）：在 2018 年以后利好 A 股和铜、利空债券，IC 约 ±0.2，但 2009–2017 年不成立。说明宏观和资产的关系有阶段切换。
- **国内收益率曲线**：tushare 的 `yc_cb` 只有 2016-06 以后的数据，样本内无法评估，未使用。

| 方案 | 夏普，样本内 | 夏普，样本外 | 回撤，样本内 | 回撤，样本外 | 实盘期相关 |
|---|---|---|---|---|---|
| 复刻基准（无宏观） | 1.32 | 1.91 | -2.9% | -3.5% | 0.94 |
| 四因子先验倾斜（增长/通胀/流动性/实际利率） | 1.16 | 1.89 | -3.0% | -3.5% | 0.93 |
| 信用脉冲倾斜 | 1.12 | 2.00 | -3.2% | -3.1% | 0.95 |
| 滚动 IC 自适应 | 1.31 | 1.88 | -3.0% | -3.2% | 0.94 |
| 美债实际利率（候选） | 1.36 | 1.99 | -2.5% | -3.6% | 0.93 |

**上表的样本外一栏不是干净的样本外**：选「美债实际利率」而不选「信用脉冲」、选 120 日窗口，这两个决定都看过 2018–2026 年的结果。所以这一行的样本外数字偏乐观，不能当作真实增益的证据。

**以逐年滚动检验为准**：从 2014 年起，每年初只用过去 5 年的夏普，从全部候选方案里挑一个，用到当年。

| 2014–2026-09 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|
| 复刻基准（无宏观） | 8.53% | 1.809 | -3.48% |
| 逐年滚动选择宏观方案 | 8.72% | 1.817 | -3.90% |
| 固定用美债实际利率（事后选定，仅供参考） | 8.96% | 1.875 | -3.58% |

滚动选择 13 年里有 12 年都挑中了美债实际利率，说明这个方向在历史上一直看起来最好；但真正按时间顺序执行时，夏普基本没变，最大回撤反而更深。

**结论：宏观叠加目前看不出真实增益，差距在随机波动范围内，不建议采用，默认仍用 `FINAL`。** `config.MACRO` 保留为候选，可以继续积累样本外数据观察。

候选方案的规则：
- **信号**：美国 10 年期 TIPS 收益率的 120 日变化，做 750 日 z 值。
- **调整**：只调黄金和美股的预算，乘以 e^(−0.5z)；z 大于 1 时，调仓日剔除这两类资产。
- **固定参数下的全样本表现（含后见之明）**：年化 7.40% → 7.72%，夏普 1.63 → 1.69，18 年里 13 年跑赢。

**和指数的关系**：
- **美股持仓更吻合**：加上实际利率叠加后，美股归因的持仓一致率从 0.73 升到 0.80，和月报 9 月评论吻合（因美债长端收益率上行，没有持有美股）。指数对美股可能用了类似的利率逻辑。
- **黄金略差**：黄金这一项的吻合度略有下降，所以整体复刻相关并没有提高（0.943 → 0.929）。

**当前读数（2026-10-27）**：实际利率 z = 1.80，高于阈值，下一次调仓（10-30）剔除黄金和美股。宏观版最近几期已经没有持有这两类资产。
